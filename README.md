# CSルール研究室

「突破率から探す」で1位を選ぶと、CSファイナルだけを探索します。1位の1試合勝率は相手が2位でも3位でも共通の値を入力できます（初期値50%）。ファーストの条件は探索から外し、最大試合数もファイナルのみを表示します。「このルールを試す」ではファイナルのルールと共通勝率を通常タブへ適用します。通常タブのファースト設定は維持されますが、この共通勝率の仮定では1位の突破率に影響しません。

自分で1つのCSのルールを作り、理論上のCS突破確率とシミュレーションを比較する趣味用アプリです。公開前の確認用で、アップロードしていません。

## 確認方法

`index.html`をブラウザーで開きます。ビルド・サーバー・外部ライブラリは不要です。別途、全ファイルをまとめた単独の`CSルール研究室-確認用.html`も用意しています。

## 使い方

1. ファーストとファイナルの先取勝数、1位への勝利アドバンテージを設定します。
2. 2位対3位・1位対2位・1位対3位の1試合勝率を設定します。
3. 順位別のCS突破確率と下剋上確率を確認します。
4. 開催回数（1〜100,000回）を入力してシミュレーションを開始します。
5. 下剋上回数・割合・理論値との差・順位別の回数・最初の最大100回の結果を見比べます。

実行するたびに新しい集計を開始します。途中停止では完了分を表示します。ルール・勝率の変更時には古い結果を消します。設定はブラウザー内に保存します。初期化で元に戻せます。

## モデル

2位と3位がファーストを戦い、勝者が1位とファイナルを戦う構成。試合は独立、対戦勝率は一定、引き分けなし。アドバンテージは1位の開始勝数です。先取勝数は1〜30、付与勝数は0以上かつファイナル先取勝数未満です。

理論値は動的計画法で計算します。シミュレーションは理論値から勝者を抽選するのではなく、Math.randomによる疑似乱数で各試合を行い、先取勝数に到達したら終了します。

|方式（全対戦50%、ファースト2勝先取）|1位進出|下剋上|
|---|---:|---:|
|4勝先取・1勝付与|65.625%|34.375%|
|5勝先取・2勝付与|77.34375%|22.65625%|
|4勝先取・2勝付与|81.25%|18.75%|

引き分け・中止・期限・同率時の上位優先・球場・投手・疲労は扱いません。通常方式は比較用の簡略モデルです。実験結果には偶然のばらつきがあり、理論値と完全一致するとは限りません。

## テストと構成

`node --test model.test.cjs`で既知値、全列挙との一致、境界値、抽選順序、集計、固定乱数10万回の理論値との整合を確認できます。

- `model.js`：確率計算・入力検証・試合単位のシミュレーション
- `app.js`：設定・比較・実験の進行管理
- `index.html`、`style.css`、`simulation.css`：画面とモバイル表示

新しいルールのひな形はmodel.jsのpresetsに追加できます。引き分けなど終了条件を変える場合は計算とシミュレーションの両方を拡張してください。

## 確認後のGitHub Pages公開手順

## 突破率からルールを探す

アプリ内の「突破率から探す」タブで目標順位（1〜3位）、目標突破率、許容差、探索する先取勝数・付与勝数の上限を指定します。既存の1試合勝率を固定し、指定範囲内の整数ルールをすべて評価します。合致する候補がないときは目標に近い順に表示します。

候補は目標との差・最大試合数で比較できます。「このルールを試す」で通常タブに適用し、同じ設定でシミュレーションできます。最大試合数は (2×ファースト先取勝数−ファースト付与勝数−1) + (2×ファイナル先取勝数−付与勝数−1) です。同じ突破率でも試合数の違うルールは別候補として表示します。

`search.js`・`search.css`も公開用ファイルに含めてください。

### GitHub Pagesの設定

新しいリポジトリの直下にこのフォルダーの内容を配置し、Settings → Pages → Deploy from a branch → main / (root)を選びます。外部サービスへの公開はまだ行っていません。

CS突破は日本シリーズへの出場権を得ることです。日本シリーズの試合は計算しません。画面には各ステージの対戦と実際に必要な残り勝数を表示します。

ファーストでも2位への付与勝数を設定できます（初期値0）。2位に付与した勝数はファイナルへ持ち越しません。逆引きではファースト付与勝数の上限も探索条件です。
